# 星海潮汐 - 文字修改帮助手册

本手册说明如何修改「星海潮汐」游戏里的所有文字（中英文），无需改动游戏逻辑。

---

## 一、文字在哪里

游戏里**所有文字都集中在一处**：`data/i18n-data.js`

```js
const I18N = {
  zh:{            // ← 中文文案
    title:"星海潮汐",
    ...
  },
  en:{            // ← 英文文案
    title:"Star & Tide",
    ...
  }
};
```
---

## 二、如何修改（3 步）
### 修改示例

**需求：把首页主标题从「星海潮汐」改成「星海之声」**

`zh` 块修改：
```js
title:"星海之声",          // ← 改这里
```
`en` 块同步修改：
```js
title:"Star & Sound",      // ← 英文同步改
```

> ⚠️ 中英文都要改，且保持 key 一一对应。只改引号内的文字，不要动 key 名、引号与逗号。

## 四、占位符说明（务必保留）

部分文案含有**占位符**，修改时请原样保留，否则显示会异常：

| 占位符 | 含义 | 示例 |
|--------|------|------|
| `{n}` | 关卡序号 | `第 {n} 关` → 显示「第 1 关」 |
| `{t}` | 时间（秒） | `你探索了 {t} 秒` → 显示「你探索了 42 秒」 |
| `\n` | 换行符 | `infoHowToBody` 等用 `\n` 分段，保留即可换行 |

## 五、相关配置（非文字，按需调整）

以下不属于文字，但维护时常会一起改，列在此处备忘：

- **关卡数量与时长**：搜索 `const LEVELS`，修改每个 `{id, duration}` 的 `duration`（单位：秒，`Infinity` 表示无尽模式）。
- **测试模式**：`const wasTest = false;` 改为 `true` 后，每关时长变为 5 秒，便于快速预览结算画面。

---

## 六、注意事项

1. **中英文都要改**，保持 key 一一对应。
2. 只改**引号内的文字**，不要动 key 名、引号、逗号与括号。
3. 含 `{n}` / `{t}` / `\n` 的文案，占位符必须原样保留。
4. 修改后如未生效，请**强制刷新**（`Ctrl + Shift + R`）清缓存。
5. 本游戏支持直接**双击 HTML 打开**（`file://`），无需服务器。
