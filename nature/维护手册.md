## 一、中英文名称修改

网站所有文本均通过 **国际化（i18n）** 机制管理，修改名称/文案只需编辑数据文件，无需改动 HTML 页面。

### 1.1 需要编辑的文件

| 文件 | 说明 |
|------|------|
| `js/i18n-data.js` | **主文件**（页面实际加载的数据） |


### 1.2 文件结构说明

```js
const I18N_DATA = {
  "en": {
    "site_title": "Nature's Symphony",      // ← 英文
    "site_subtitle": "Listen to the Music of Nature",
    ...
  },
  "zh": {
    "site_title": "聆听大自然",              // ← 中文
    "site_subtitle": "聆听大自然的音乐",
    ...
  }
};
```

### 1.3 常用翻译键对照表

| 翻译键 | 用途 | 英文示例 | 中文示例 |
|--------|------|----------|----------|
| `site_title` | 网站主标题 | Nature's Symphony | 聆听大自然 |
| `site_subtitle` | 网站副标题 | Listen to the Music of Nature | 聆听大自然的音乐 |
| `btn_start_concert` | 首页按钮 | Start Nature's Concert | 开始大自然的音乐会 |
| `theme_forest` | 主题名-森林 | Forest | 森林 |
| `theme_ocean` | 主题名-大海 | Ocean | 大海 |
| `theme_lake` | 主题名-湖泊 | Lake | 湖泊 |
| `theme_spring` | 主题名-泉水 | Spring | 泉水 |
| `theme_forest_desc` | 首页卡片描述 | Immerse yourself... | 沉浸在古老树木... |
| `player_next` | 播放器随机按钮 | Explore Nature's Symphony | 探索《大自然乐章》 |
| `nav_about` | 导航-关于 | About | 关于 |
| `nav_share` | 导航-分享 | Share | 分享 |
| `back_home` | 返回首页 | Back to Home | 返回首页 |
| `back_prev` | 返回上一页 | Back | 返回 |

### 1.4 修改示例

**需求：将网站名称从"聆听大自然"改为"自然之声"**

编辑 `js/i18n-data.js`：
```js
"zh": {
  "site_title": "自然之声",          // ← 改这里
  "site_subtitle": "聆听自然的声音",  // ← 副标题也可一并修改
  ...
}
```
### 1.5 修改主题详情页的标题/地点/描述

主题播放页的标题、地点、录制时间、描述文字在 **配置文件** 中管理：

| 文件 | 说明 |
|------|------|
| `data/conf.js` | **主文件**（页面实际加载） |


位置在 `themes` 数组 → 对应主题 → `info` 字段：

```js
{
  "id": "forest",
  "info": {
    "en": {
      "title": "Forest",                    // 英文标题
      "location": "Black Forest, Germany",  // 英文地点
      "time": "June 2024, Early Morning",   // 英文时间
      "description": "Deep within..."       // 英文描述
    },
    "zh": {
      "title": "森林",                      // 中文标题
      "location": "德国黑森林",             // 中文地点
      "time": "2024年6月，清晨",            // 中文时间
      "description": "在古老的黑森林深处..." // 中文描述
    }
  }
}
```

## 二、图片和音频素材替换

### 2.1 目录结构

```
nature/
├── audio/                  ← 音频文件
│   ├── forest.wav
│   ├── ocean.wav
│   ├── lake.wav
│   └── spring.wav
├── theme/                  ← 图片文件
│   ├── home/              ← 首页卡片封面图
│   │   ├── forest.jpg
│   │   ├── ocean.jpg
│   │   ├── lake.jpg
│   │   └── spring.jpg
│   ├── forest/            ← 森林主题背景轮播图
│   │   ├── 1.jpg
│   │   ├── 2.jpg
│   │   └── 3.jpg
│   ├── ocean/             ← 大海主题背景轮播图
│   │   ├── 1.jpg
│   │   ├── 2.jpg
│   │   └── 3.jpg
│   ├── lake/              ← 湖泊主题背景轮播图
│   │   ├── 1.jpg
│   │   ├── 2.jpg
│   │   └── 3.jpg
│   └── spring/            ← 泉水主题背景轮播图
│       ├── 1.jpg
│       ├── 2.jpg
│       └── 3.jpg
```

### 2.2 替换音频

**方法：直接用新文件覆盖旧文件（保持文件名不变）**

| 主题 | 音频路径 | 格式 |
|------|----------|------|
| 森林 | `audio/forest.wav` | WAV |
| 大海 | `audio/ocean.wav` | WAV |
| 湖泊 | `audio/lake.wav` | WAV |
| 泉水 | `audio/spring.wav` | WAV |

**操作步骤：**
1. 准备好新的音频文件
2. 将文件重命名为对应的名称（如 `forest.wav`）
3. 复制到 `audio/` 文件夹，覆盖原文件
4. 完成，无需修改任何代码

> 💡 如需使用 MP3 等其他格式，需同时修改配置文件中的路径（见 2.4）。

### 2.3 替换图片

#### 首页封面图（卡片缩略图）

| 主题 | 图片路径 | 建议尺寸 |
|------|----------|----------|
| 森林 | `theme/home/forest.jpg` | 400×500px 以上 |
| 大海 | `theme/home/ocean.jpg` | 400×500px 以上 |
| 湖泊 | `theme/home/lake.jpg` | 400×500px 以上 |
| 泉水 | `theme/home/spring.jpg` | 400×500px 以上 |

#### 主题背景轮播图（播放页全屏背景）

| 主题 | 图片路径 | 建议尺寸 |
|------|----------|----------|
| 森林 | `theme/forest/1.jpg`、`2.jpg`、`3.jpg` | 1920×1080px 以上 |
| 大海 | `theme/ocean/1.jpg`、`2.jpg`、`3.jpg` | 1920×1080px 以上 |
| 湖泊 | `theme/lake/1.jpg`、`2.jpg`、`3.jpg` | 1920×1080px 以上 |
| 泉水 | `theme/spring/1.jpg`、`2.jpg`、`3.jpg` | 1920×1080px 以上 |

**操作步骤：**
1. 准备好新图片（建议 JPG 格式）
2. 将文件重命名为对应的名称（如 `1.jpg`）
3. 复制到对应主题的文件夹，覆盖原文件
4. 完成，无需修改任何代码

### 2.4 修改素材路径（更换文件名/格式时）

如果新素材的文件名或格式与原来不同，需要修改配置文件：

编辑 `data/conf.js`：

```js
{
  "id": "forest",
  "audio": "audio/forest.wav",        // ← 修改音频路径
  "images": [
    "theme/forest/new1.jpg",          // ← 修改背景图路径
    "theme/forest/new2.jpg",
    "theme/forest/new3.jpg"
  ],
  "cover": "theme/home/forest-new.jpg" // ← 修改首页封面路径
}
```

### 2.5 增加/减少轮播图数量

背景轮播图数量不固定，可自由增减：

```js
// 增加到 5 张
"images": [
  "theme/forest/1.jpg",
  "theme/forest/2.jpg",
  "theme/forest/3.jpg",
  "theme/forest/4.jpg",
  "theme/forest/5.jpg"
]

// 减少到 2 张
"images": [
  "theme/forest/1.jpg",
  "theme/forest/2.jpg"
]
```

> 💡 轮播间隔时间可在 `settings.imageInterval` 中调整（单位：毫秒，默认 8000）。

### 2.6 素材要求汇总

| 类型 | 格式 | 大小建议 | 备注 |
|------|------|----------|------|
| 音频 | WAV / MP3 | 无限制 | 建议使用循环无缝音频 |
| 首页封面 | JPG / PNG | < 500KB | 竖版比例 3:4 效果最佳 |
| 背景轮播图 | JPG / PNG | < 2MB | 横版 16:9，分辨率 ≥ 1920×1080 |

---

## 三、注意事项

1. **文件名大小写**：路径区分大小写，请确保文件名与配置中完全一致。
2. **格式**：更换默认格式需要同步修改配置文件。
3. **浏览器缓存**：替换素材后如未生效，请强制刷新（Ctrl + Shift + R）。
4. **file:// 兼容**：本网站支持直接双击 HTML 文件打开，无需服务器。
